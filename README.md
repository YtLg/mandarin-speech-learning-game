# Language Learning Game
A language learning game to teach and improve spoken Mandarin Chinese by simulating spoken dialogue with various characters and providing analytical feedback on the player's pronunciation.
This project utilises a custom made API and audio analysis pipeline to score and provide feedback on speech input made within the game.
Completed as a part of my 3rd year dissertation.

Features:
1. Speech input for interaction with NPC characters
2. Speech to text transcription & pronunciation accuracy score
3. Audio analysis pipeline to break down pronunciation further and provide feedback.
